# Security policy

Пароли никогда не сохраняются и не логируются открытым текстом. Используется
scrypt с параметрами `N=32768`, `r=8`, `p=1`, случайной солью 16 байт и ключом
32 байта; строка hash включает версию алгоритма и параметры.

JWT подписываются HS256, содержат `sub`, `iat` и 24-часовой `exp`. В production
задайте уникальный `REALWORLD_JWT_SECRET`; fallback предназначен только для
локальной разработки и печатает предупреждение.

SQLite foreign keys включаются при каждом новом соединении pool. Все значения
пользователя передаются в SQL как bound parameters через `typed-sql`.

Сообщайте о проблемах приватно владельцу репозитория. Не прикладывайте токены,
пароли или production database URLs к issue.
